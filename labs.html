WINDOWS · COMMAND PROMPT

DOS-style commands & Batch

Open the real Windows Command Prompt: press Win + R, type cmd, and press Enter. These are modern Windows commands, not a perfect copy of original MS-DOS.

cd
dir
mkdir RetroPractice
cd RetroPractice
echo Hello from a real command prompt>hello.txt
type hello.txt

Observe: cd shows the current directory; dir lists its contents; the final command reads the file you created. Run this in a practice folder you own.

JAVASCRIPT · REAL RUNTIME

Run JavaScript locally

The JavaScript workshop below executes your code in a browser JavaScript engine. For scripts outside a webpage, install Node.js from its official website, save code as lesson.js, then run node lesson.js in a terminal.

const name = "learner";
console.log(`Hello, ${name}!`);

Change the value, run again, and compare the output. No paid API or account is required.

POWERSHELL

Use the actual PowerShell

Open PowerShell or Windows Terminal. Inspect before changing system state.

Get-Location
Get-ChildItem
Get-Help Get-ChildItem
"Hello from PowerShell"

PowerShell pipelines pass structured objects, not just plain text. Start with read-only commands and read help before trying administrative actions.

LINUX · macOS · BASH

Use a real shell

Open your system terminal, or use WSL on Windows to install a Linux environment. Commands vary by operating system.

pwd
printf '%s\n' 'Hello from the shell'
mkdir -p practice
cd practice
printf '%s\n' 'notes' > notes.txt
cat notes.txt

These commands create and read a file in the current working directory. Understand every command before running it.

LEGACY WINDOWS SCRIPTING

JScript & VBScript

These lessons teach the real syntax and history of Windows Script Host. They do not run in this website: execution requires a compatible Windows environment, and VBScript support is deprecated or restricted on modern Windows versions.

// JScript example: hello.js
WScript.Echo("Hello from Windows Script Host");

Use only a machine you control. Do not run unknown scripts or examples that delete files, change settings, or access the network.

PYTHON · PHP · OTHER LANGUAGES

Install the correct runtime

Python scripts need Python; PHP scripts need PHP; Perl, Ruby, Lua and Tcl each have their own runtimes. Static hosting publishes teaching materials but does not install or execute those runtimes for you.

Each course explains how to save a source file, run it locally, interpret the result, and troubleshoot common errors.

Important: GitHub Pages hosts static files only. This site provides actual teaching and a real browser JavaScript runner; it cannot execute DOS, Batch, PowerShell, VBScript, Bash, Python or PHP on GitHub's server. Follow the setup steps to run those languages in their real environments.
