# RetroScript Academy

A free, retro-inspired static learning website for scripting languages, from absolute beginner to advanced.

## Included
- Responsive retro computer-lab design
- Course directory for DOS, Batch, JavaScript, Microsoft JScript, VBScript, PowerShell, Bash, Python, PHP and a scripting-language atlas
- Lesson viewer with annotated examples
- Browser-only DOS filesystem simulator
- JavaScript playground isolated in a sandboxed iframe
- Quick-reference cards and a quiz
- Local course progress using browser storage
- No backend, database, paid API, or AI service

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for the Pages deployment and open the URL GitHub provides.

The site is plain HTML, CSS, and JavaScript; no build step or dependency installation is required.

## Important runtime notes
GitHub Pages serves static files. It cannot execute actual DOS batch files, Windows Script Host JScript, VBScript, PowerShell, Bash, Python, or PHP on the server. Their lessons are educational examples and the DOS lab is a simulation. Only the JavaScript playground runs code in the browser. Legacy scripting languages may be disabled or deprecated on modern operating systems; use appropriate, controlled environments when studying them.

## Local development
Open `index.html` directly in a browser or use any static local web server. No build command is needed.
